# Permutation Domain

**Definition (canonical):** a permutation is a **generated, valid configuration** constructed from:

```
Base Article + Property Values + Relation/Dependency Conditions + Encoding
```

It is **not** simply an existing final-Article row — see [Permutation_Model.md](./Permutation_Model.md).
