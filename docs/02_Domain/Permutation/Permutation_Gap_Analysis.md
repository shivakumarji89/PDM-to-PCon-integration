## Summary of required changes, ranked by evidence strength

1. **Tokenize, don't just order, the CodeScheme `body` string** (items 3-5) — the single highest-leverage fix; every downstream separator/grouping/literal problem is a direct consequence of discarding tokens except for ordering.
2. **Stop emitting `<artNr type="final">` in generated input OBX**, or fix its algorithm to match the tokenized grammar (item 8) — currently both structurally atypical for an input file and computed with a disproven no-separator algorithm.
3. **Add relation evaluation** for both validity-gating and computed (`R`-type) properties (items 1, 6) — required for any range using a script-style scheme (Aeron-pattern) and for any range with hierarchy/artbase restrictions.
4. **No change needed** to pricing-key logic (item 9) or to the fact that `type="varcode"` is currently omitted (item 7, correct as-is).
