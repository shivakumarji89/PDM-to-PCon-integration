# Fact Sheet

# OCD Article texts

This document contains recommendations for the creation of article texts in OFML data and illustrates their
use in various pCon applications. The recommendations in this document are based on the recommendation of
the standardization committee of the Industrieverband Büro und Arbeitswelt e. V. (IBA) (Interior Business Asso-
ciation) for "Uniform customer-oriented article descriptions". Further details can be found there.

# 1 Overview

There are three types of article text:

• Short text
This text should contain a brief description of the basic article.
It is usually displayed in overviews of all articles of a project (for example in the article tree) and in ex-
ceptional cases in article lists and forms. The short text should only contain one line (max. 50 charac-
ters).

• Long text
The long text contains a more detailed description of the basic article. Usually this is the text that ap-
pears at the item – and article list. It should describe all essential properties of the item that are not
configurable by the customer. This includes the information about the fixed dimensions, if these are
not included in the variant text (see below). If possible, these measurements should be listed at the
end of the long text.
The recommended unit of measurement for Germany is millimeters (mm), otherwise centimeters
(cm). For the United States Inches is used.

The dimensions are specified in the following order: width, depth, height.
e.g. 800 x 430 x 720 mm (WxDxH)
By default, either only the long text or only the short text is displayed. Therefore, the long text must
be understandable independently of the short text.

NEW: The individual lines of the long text are interpreted as paragraphs, i.e. each line can be
wrapped by the applications as required (continuous text). Each new line forces a line break by the
applications.

• Variant text
The variant text describes the properties of the article (variants) that can be configured by the cus-
tomer. Please do not use any codes (abbreviations) for characteristic and/or value only. The proper-
ties should be described textually. Usually the text is shown after the long and short text at the article
lists or forms and supplements it. Long text and variant text belong together in terms of content.
