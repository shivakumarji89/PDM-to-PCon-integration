# 27 — Business Rules Index

*Master, cross-referenced index of every business rule (`BR-*`) extracted from the legacy PDM Maintenance application. Each rule keeps its original module id and links back to the source document where it is proven with code/query citations.*

**Status:** Aggregated from verified module extractions; unproven items marked UNKNOWN.

> **How to read this index.** IDs are reproduced **exactly as they appear** in the source documents — including intentional gaps and out-of-order/non-contiguous ranges (e.g. `BR-ATTR` skips 003/008/009/012; `BR-CFG` jumps 021→041→050→…→901; `BR-PRICE` starts at 010; `BR-OCD` includes the variant ids `021b`/`031b`). **No missing ids have been invented.** Where a source doc references an id it never enumerates as a full rule (e.g. `BR-PVAL-001`/`002`, `BR-CFG-070-flag`), that is called out explicitly and **not** counted as an enumerated rule.
