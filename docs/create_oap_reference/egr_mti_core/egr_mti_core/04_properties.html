Properties

Properties hold all information about their names, values, visibility, flags, possible translations… They provide an easy way to filter articles or to create new articles within a planning group.

 1# all metatypes of package ::man::series
 2all_metatypes = data_man.get_package("man", "series").metatypes
 3
 4# only metatype MT_SE_Table
 5mt_table = all_metatypes["MT_SE_Table"]
 6
 7# iterate through all articles of this metatype
 8for article in mt_table.articles:
 9
10    # apply various filters here, using properties provided by the MT
11    # e.g. use only article with fix height...
12    if article.poly_props["GSE_HeightAdjust"].value != "SE_HA_Fix":
13        continue
14    # ...and depth 800
15    if article.poly_props["GSE_Depth"] != 800:
16        continue
17
18    # do something with whatever article passed this filter
19    print(article.artno, article.unique_key)
20    ...

get_values() → set[int | float]

Returns all values this property can take. The Return value can be one of the following options:

  • in case of integer with no raster, returns a set with a range from min to max.

  • in case of integer with raster, returns a set with a range from min to max regarding the raster

  • in case of non-integer returns a range from min to max regarding the raster

  • if the property is not enumerable (is_enumerable() == False) raises a ValueError
