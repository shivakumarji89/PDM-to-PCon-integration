Metatype

MetaType objects can be generated via the GoPackage which is accessible via the DataManager. They contain every information about properties and their values, flags, article numbers, classes and many many more. This information may be used for example for filtering when creating neighbors…

1# 'load' the metatype series
2data_man.add_meta_series(MetaSeries("man", "series", "1", "ANY", False))
3
4# all metatypes of package ::man::series
5all_metatypes = data_man.get_package("man", "series").metatypes
6
7# only metatype MT_SE_Table
8mt_table = all_metatypes["MT_SE_Table"]
class egr_mti_core.mt.Metatype(name, package)

Bases: object

Class for a Metatype

A Metatype consists of it’s default options (GType, GMode, GSetup, …). It also knows its Properties and their values, its children, AttachPoints and Actions.
