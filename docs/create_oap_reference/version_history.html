Version history

Every config_oap.py declares a requires_create_oap. This version is usually identical to the version of create_oap and prevents silent semantic changes when using a newer of this app.

This should not be confused with the OAP version of the generated files, even if the two are linked (the generated OAP version is part of the semantics covered by requires_create_oap). Often (though not always) only one is supported by a particular version of create_oap. See the table below for details on the existing and supported versions.
