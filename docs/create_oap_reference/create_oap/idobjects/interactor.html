Interactor

class create_oap.create_oap.Interactor(oap, name, symbol)

Bases: IdObject

Construct a new Interactor.

Parameters:

  • oap (OAP) – The oap-object

  • symbol (Symbol) – Symbol to be displayed for this interactor.

condition: str

OAP-expression that evaluates to a boolean.

actions: OrderedDict

A dictionary with name as key and Action as value.

symbol: Symbol

The interactor’s symbol.

symboldisplays: list

A list of SymbolDisplay used by the symbol.

set_position(x, y, z)

Creates a SymbolDisplay and sets its position (a.k.a offset) to given xyz-coordinates. For multiple symboldisplays (e.g. with additional viewing angles) use create_symboldisplay directly.

Parameters:

  • x (string) – x-position in meters, can be a methodcall evaluating to a numeric value

  • y (string) – y-position in meters, can be a methodcall evaluating to a numeric value

  • z (string) – z-position in meters, can be a methodcall evaluating to a numeric value

set_position_expr(expr)

Creates a SymbolDisplay and sets its position (a.k.a offset) via an OAP-expression. For multiple symboldisplays (e.g. with additional viewing angles) use create_symboldisplay directly.

Parameters:

expr (str) – Should be an OAP expression that evaluates to a Sequence of three Float values (e.g. “[0,0,0]”). Can be a MethodCall.

set_hidden_mode(hidden_mode)

Set hidden mode for interactor. If not called defaults to 1.

Parameters:

hidden_mode (int (0|1)) –

  • 0 - always visible

  • 1 - can be hidden by geometries

add_action(action)

Add an Action to be executed by clicking the interactor. Can be called multiple times.

Parameters:

action (Action) – an action to be executed.

Note: It is currently not possible to add the same action multiple times.

get_action(name)

Get the Action with the given name

Parameters:

name (str) – name of the action

Raises KeyError, if no action with given name exists.

Returns:

Action

get_actionlist(name)

Get the ActionList with given name. ActionLists generated automatically via convenience function create_interactor_choicelist have the same name as the interactor.

Parameters:

name (string) – Name of the actionlist

Raises KeyError, if no actionlist with given name exists.

Returns:

ActionList

insert_action(pos, action)

Insert an Action at the given position to control order. Behavior similar to list.insert().

Parameters:

  • pos (int) – Insert an action at given position.

  • action (Action) – The action to be inserted.

reorder_actions(action_names)

Reorders the list of Actions

Parameters:

action_names (list[str]) – Action-names in new order.

Action-names not in the list, but in the existing actions, will be removed. Action-names existing in the list, but not in the current actions, will raise a KeyError.
