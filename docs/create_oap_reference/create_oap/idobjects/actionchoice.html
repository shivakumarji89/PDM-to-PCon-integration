ActionList

class create_oap.create_oap.ActionList(oap, name)

Bases: list

Construct a new ActionList . Not to be created manually. Use create_action_choicelist() or create_interactor_choicelist() instead.

Parameters:

  • oap (OAP) – oap-instance

  • name (str) – a name for this actionchoice

oap

oap-object

name

name of this actionlist

property id

Contains the ID of this IdObject. Usually created of the name and a styleguide conforming prefix.

add_item(action, text=None, image_set=None, condition='')

Adds given Action with given Text and ImageSet to this actionlist.

An optional condition can be given. If condition is an empty string or an OAP-Expression that will evaluate to True at runtime, show item in list, otherwise hide it.

add_nested(name, *, text=None, image_set=None, condition='', title=None)

Creates another actionlist within an existing one to ‘nest’ actionlists. Although text and image_set are optional at least one of these two has to be defined.

Parameters:

  • name (str) – a name for the new ActionList

  • text (ImageSet) – (opt.) text to be displayed

  • image_set – (opt.) image_set to be shown

  • condition (str) – (opt.) a condition (should be a string containing an OAP-Expression that will evaluate to a boolean)

  • title (Text) – (opt.) title to be displayed

Returns:

ActionList

copy(name)

Creates a copy of this ActionList with a new name.

Parameters:

name (str) – name for the new ActionList

Returns:

ActionList
