OAP

The OAP-object is the main part of create_oap it provides a lot of helper and convenience methods to create interactors, action, messages, texts and all the IdObjects. An instance of OAP is automatically provided by create_oap, so usually there is no need to create it manually.

The following sections provide a slight overview over these functions.

Creating interactors

There is a set of convenience methods to create interactors. In a lot of cases these methods are sufficient to create a simple interactor.

Every interactor has a name. It will be used to automatically create an ID according to the OAP-styleguide. The ID can be accessed via the property id. (e.g. my_interactor.id)

Create an Interactor with an included PropEdit.

Parameters:

  • title (str) – The name of the Text object that should be used as the dialog title. A text object with this name will be implicitly created if it does not already exist.

  • properties (list[str]) – list of property keys (e.g. [“Width”,”Depth”])

  • propclasses (list[str]) – list of property class keys (e.g. [“Dimensions”])

  • object (Object) – opt. OAP-object providing the properties/classes (default: default_objects[“self”])

  • symbol_type (SymbolType) – opt. interactor symbol (default: SymbolType.Edit)

  • state_restriction (StateRestriction) – opt. global state restriction (default: StateRestriction.None_)

Returns:

Interactor

The following code fragment creates a propedit interactor with two properties (“MyProp1” and “MyProp2”). MyHeader is the title to be displayed. MyProp1 and MyProp2 are the properties to be shown when clicking on the interactor.

ia = oap.create_interactor_propedit("MyProps", "MyHeader", ["MyProp1", "MyProp2"], [])
OAP.create_interactor_choicelist(name, symbol_type=SymbolType.Add, symbol_size=SymbolSize.large, *, title=None)

Create an Interactor with an included ActionChoice and ActionList. The ActionList is available to be filled with Actions via add_item().

Parameters:

  • name (str) – The name to be used in oap-tables for this interactor, the accompanying actionchoice, actionlist and action, created.

  • symbol_type (SymbolType) – opt. interactor symbol (default: SymbolType.Add)

  • symbol_size (SymbolSize) – opt. interactor size (default: SymbolSize.large)

  • title (str) – The name of the Text object that should be used as the dialog title. A text object with this name will be implicitly created if it does not already exist.

Returns:

Interactor

The following code fragment creates a choicelist interactor and adds actions to it’s implicitly created ActionList. As the code demonstrates the actionlist can be accessed by calling get_actionlist on the returned interactor, passing the same name as was given to create_interactor_choicelist.

 1# create interactor
 2ia = oap.create_interactor_choicelist("Colors")
 3
 4# variable to hold the actionlist
 5ac_l = ia.get_actionlist("Colors")
 6
 7# create action to set a value at a property
 8action_color_blue = oap.create_action_propchange_set_value("Color_Blue", "Color", OfmlSymbol("Blue"))
 9# add this action to the actionlist
10ac_l.add_item(action_color_blue, oap.get_or_create_text("Blue"))
11
12# create action to set a value at a property
13action_color_green = oap.create_action_propchange_set_value("Color_Green", "Color", OfmlSymbol("Green"))
14# add this action to the actionlist
15ac_l.add_item(action_color_green, oap.get_or_create_text("Green"))

Create an Interactor that deletes given object.

Parameters:

  • name (str) – The name to be used in oap-tables for this interactor and the accompanying action.

  • symbol_type (SymbolType) – opt. interactor symbol (default: SymbolType.Delete)

  • symbol_size (SymbolSize) – opt. interactor size (default: SymbolSize.large)

  • object (opt. Object) – object to be deleted. If None, the selected object will be deleted. (default: None)

Returns:

Interactor

This convenience method deletes an object. By default this object is the selected element.

ia = oap.create_interactor_delete("DelArticle")

If a different object shall be deleteted, e.g. an element of the planning group while the planning group itself is selected, the object can be passed to the method. If you have a method that returns the required object you can use this to create an object accessible by OAP.

# create an object by making an action that calls a method of
# the planning group
last = Object_MethodCall(oap, "last", xOiJointPlGroup.lastObj.action())
ia = oap.create_interactor_delete("DelArticle", object_ = last)

OAP.create_action_dimchange(name, dimension, prop, multiplier, precision, separate='', third_dim='', condition='')

Creates an Action to interactively change dimensions along with a corresponding DimChangeSet and DimChangeEntry.

The DimChangeSet is available via the dimchangeset property of the returned action and can be used to add further dimensions (add_dimchange_entry).

Symbols

Symbols are the representation of an OAP interactor. This can be e.g. , an arrow or another image. The look of these images is standardized on every application (pCon.box, pCon.planner, …) to ensure a familiar Look&Feel. Each Symbol defines type, position and size. Every interactor needs a symbol to be displayable, hence each create_interactor_* method creates a symbol by default. (Of course the used symbol can be modified if needed.)

Note

Do not mistake Symbols in create_oap with Symbols in the mt module. Although they both are named equally, they are used in different contexts. In order to avoid confusion Symbols for metatypes are renamed OfmlSymbol when being used in create_oap.

  • OfmlSymbol means the OFML type Symbol “@foo” with a value accessible via .value

  • Symbol means an OAP-Symbol with a position, a size and a type

adjust_view_angle(direction=SymbolDirection.TopView, view_angle='360')

Show interactor only while within viewing range.

Parameters:

  • direction (SymbolDirection) – defining “front” of the symbol (default: SymbolDirection.TopView)

  • view_angle (str) – OAP expression evaluating to a numeric value representing the angle at which this interactor is visible (default = “360”)

make_3d(direction=SymbolDirection.TopView, view_angle='360', orientation_x=SymbolOrientation.X)

Use 3-dimensional interactors. 3-dimensional interactors adapt their angle and position according to the users viewing angle.

Parameters:

  • direction (SymbolDirection) – orientation of the symbol (default: SymbolDirection.TopView)

  • view_angle (str) – OAP expression evaluating to a numeric value representing the opening angle of the visibility range in degrees (default = “360”)

  • orientation_x (SymbolOrientation) – Orientation of x-axis for 3d symbols
